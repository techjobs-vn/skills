# Working on this repository

Agent skills for tech job search in Vietnam on top of the techjobs.vn MCP server. Each skill directory is installed on its own (`npx skills add`, the Claude Code and Cursor plugins), so a skill never links to another skill's files.

## Layout

The Claude directory plugin is the folder `plugins/techjobs/` (manifest, `.mcp.json`, `skills/`), submitted on its own because the directory only accepts a restricted set of files from unverified organizations. Everything else in the repository (this file, `scripts/`, `tests/`, `.github/`, the Cursor manifest) stays outside it.

- `plugins/techjobs/skills/techjobs/SKILL.md`: a mirror of https://techjobs.vn/SKILL.md, generated by job-hub (`lib/mcp/skill-md.ts`) and synced daily by `.github/workflows/sync-techjobs-skill.yml`. **Never edit it here**; change job-hub instead.
- `plugins/techjobs/skills/vn-*/SKILL.md`: a router per skill (frontmatter, menu, routing table, short rules). Detail goes in `references/<mode>.md`, which the router tells the agent to read before a mode. Keep a SKILL.md body under 200 lines.
- `scripts/shared-rules.md`: the rules block every `vn-*` SKILL.md carries between `<!-- shared-rules:start -->` and `<!-- shared-rules:end -->`. Edit it there, then `node scripts/validate-package.mjs --fix`. Its wording follows job-hub's `PROMPT_RULES` (`lib/mcp/prompts.ts`); keep the two in step.
- `tools/gross-net.mjs`: the Gross ⇄ Net calculator and its tests (`tests/gross-net.test.mjs`). It is **not shipped**: the directory accepts program files only from Verified organizations, so `vn-offer-check` works the arithmetic from `references/vn-payroll.md`. Ship it again inside the skill once the organization is Verified, and keep its numbers in step with `references/vn-payroll.md`.
- `tests/`: kept outside the skill directories so they are not installed to users.

## What lives where

The skills hold method: how to triage, score, practise and follow up. techjobs.vn holds data and the rules every client must apply the same way: the verdict, band and confidence of a saved evaluation, calibration and its minimum sample, story provenance and limits, posting signals, scopes and quotas. Never re-implement a server rule in a skill; report what the tool returns.

## Tool names

Name tools in backticks. `scripts/validate-package.mjs` fails when a `vn-*` file names a snake_case word that the synced SKILL.md does not document as a tool; a field name goes in its `NOT_TOOLS` list. So the release order is: deploy job-hub with the new tool, run the sync, then merge the skill.

## Checks

```bash
node scripts/validate-package.mjs                                        # against the mirror
node scripts/validate-package.mjs --skill-md http://localhost:3000/SKILL.md  # against job-hub `npm run dev`
node --test "tests/*.test.mjs"
```

Commits follow Conventional Commits (`feat(vn-job-search): …`, `chore(techjobs): …`). Bump the version in `.claude-plugin/plugin.json` and `.cursor-plugin/plugin.json` together.
